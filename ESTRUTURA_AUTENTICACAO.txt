                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                       CONTROLLERS                                            │
│                                                                              │

│  ├─ [HttpGet] Login() → Exibe formulário                                   │
│  ├─ [HttpPost] Login(cpf, senha)                                           │
│  │  ├─ Valida campos vazios                                                │

│  │  ├─ Se válido: SignInAsync() → Redireciona /Funcionario/Index          │

│  │  ├─ Executa SignOutAsync()                                              │

│                                                                              │
│  FuncionarioController.cs:                                                 │
│  └─ [Authorize(AuthenticationSchemes = "FuncionarioScheme")]              │
│     ├─ Index() → Lista funcionários                                        │
│     ├─ Create() → Cria funcionário                                         │
│     ├─ Edit() → Edita funcionário                                          │
│     ├─ Delete() → Deleta funcionário                                       │
│     └─ Details() → Mostra detalhes                                         │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                       REPOSITORIES (Acesso a Dados)                         │
│                                                                              │
│  IAuthRepository.cs (Interface):                                           │
│  ├─ AuthenticateFuncionario(cpf, senha) → Funcionario?                    │
│  └─ GetFuncionarioById(id) → Funcionario?                                 │
│                                                                              │
│  AuthSqlRepository.cs (Implementação):                                     │
│  ├─ AuthenticateFuncionario(cpf, senha)                                   │
│  │  ├─ Query: SELECT FROM pessoas WHERE cpf = @Cpf                        │
│  │  ├─ Valida se existe em funcionarios                                   │
│  │  ├─ PasswordHasher.VerifyHashedPassword()                              │
│  │  └─ Retorna Funcionario ou null                                         │
│  └─ GetFuncionarioById(id)                                                 │
│     ├─ Query: SELECT FROM pessoas WHERE id = @Id                          │
│     └─ Retorna Funcionario ou null                                         │
│                                                                              │
│  FuncionarioSqlRepository.cs:                                              │
│  ├─ Create(funcionario) → INSERT                                           │
│  ├─ Read() → SELECT LIST                                                   │
│  ├─ Read(id) → SELECT BY ID                                                │
│  ├─ Update(funcionario) → UPDATE                                           │
│  └─ Delete(id) → DELETE                                                    │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                       UTILITIES (Utilitários)                               │
│                                                                              │
│  PasswordHasherUtil.cs:                                                    │
│  ├─ HashPassword(plainPassword) → string (hash)                           │
│  └─ VerifyPassword(hash, plainPassword) → bool                            │
│                                                                              │
│  Usa: Microsoft.AspNetCore.Identity.PasswordHasher<Funcionario>           │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
                                    ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                       SQL SERVER (Banco de Dados)                           │
│                                                                              │
│  Tabela: pessoas                                                            │
│  ├─ id (int, PK, IDENTITY)                                                │
│  ├─ nome (varchar(50))                                                     │
│  ├─ cpf (varchar(20), UNIQUE)                                             │
│  └─ senha (varchar(256)) ← MODIFICADO para 256                            │
│                                                                              │
│  Tabela: funcionarios                                                      │
│  ├─ pessoa_id (int, FK → pessoas.id, PK)                                 │
│  └─ email_institucional (varchar(50), UNIQUE)                             │
│                                                                              │
│  Query de autenticação:                                                    │
│  SELECT p.id, p.nome, p.cpf, p.senha, f.email_institucional               │
│  FROM pessoas p                                                             │
│  INNER JOIN funcionarios f ON p.id = f.pessoa_id                           │
│  WHERE p.cpf = @Cpf;                                                       │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘

FLUXO COMPLETO DE AUTENTICAÇÃO:

1. USUÁRIO ACESSA LOGIN
   ┌─────────────────────────────────────────────────────┐
   │ GET /Auth/Login                                     │
   │ ↓                                                   │
   │ AuthController.Login()                              │
   │ ↓                                                   │
   │ return View("Login")                                │
   │ ↓                                                   │
   │ Views/Auth/Login.cshtml (Formulário exibido)       │
   └─────────────────────────────────────────────────────┘

2. USUÁRIO PREENCHE CPF E SENHA
   ┌─────────────────────────────────────────────────────┐
   │ Formulário:                                         │
   │ ├─ Campo: CPF (input type="text")                   │
   │ ├─ Campo: Senha (input type="password")             │
   │ └─ Botão: Entrar (button type="submit")             │
   └─────────────────────────────────────────────────────┘

3. SUBMIT DO FORMULÁRIO
   ┌─────────────────────────────────────────────────────┐
   │ POST /Auth/Login?cpf=XXX&senha=YYY                  │
   │ ↓                                                   │
   │ AuthController.Login(cpf, senha)                    │
   │ ↓                                                   │
   │ ModelState.IsValid?                                 │
   │ ├─ NÃO: return View(); (mostra erro)               │
   │ └─ SIM: continua...                                 │
   └─────────────────────────────────────────────────────┘

4. CONSULTAR BANCO DE DADOS
   ┌─────────────────────────────────────────────────────┐
   │ repository.AuthenticateFuncionario(cpf, senha)      │
   │ ↓                                                   │
   │ AuthSqlRepository.AuthenticateFuncionario()         │
   │ ├─ Abre conexão SQL                                 │
   │ ├─ Executa query parametrizada:                     │
   │ │  SELECT ... FROM pessoas WHERE cpf = @Cpf        │
   │ └─ Fecha conexão                                    │
   └─────────────────────────────────────────────────────┘

5. VALIDAR SENHA COM HASH
   ┌─────────────────────────────────────────────────────┐
   │ PasswordHasher.VerifyHashedPassword()               │
   │ ├─ Entrada:                                         │
   │ │  - Senha fornecida: "Teste@123" (texto puro)     │
   │ │  - Hash do banco: "AQAAAA..." (hashed)           │
   │ ├─ Comparação segura                                │
   │ └─ Resultado: Success | Failed                      │
   └─────────────────────────────────────────────────────┘

6A. SE SENHA VÁLIDA
    ┌─────────────────────────────────────────────────────┐
    │ ✅ Senha verificada com sucesso                     │
    │ ↓                                                   │
    │ Criar Claims:                                       │
    │ ├─ NameIdentifier: funcionario.Id (1)             │
    │ ├─ Name: funcionario.Nome ("João Silva")           │
    │ ├─ cpf: funcionario.Cpf ("123.456.789-00")         │
    │ ├─ email: funcionario.EmailInstitucional (...)    │
    │ └─ Role: "Funcionario"                             │
    │ ↓                                                   │
    │ Criar ClaimsPrincipal (usuário autenticado)        │
    │ ↓                                                   │
    │ await HttpContext.SignInAsync(                      │
    │   "FuncionarioScheme", principal, authProperties)  │
    │ ↓                                                   │
    │ Cookie "FuncionarioAuth" criado e enviado          │
    │ ↓                                                   │
    │ RedirectToAction("Index", "Funcionario")           │
    │ ↓                                                   │
    │ 302 Redirect → /Funcionario/Index                  │
    └─────────────────────────────────────────────────────┘

6B. SE SENHA INVÁLIDA
    ┌─────────────────────────────────────────────────────┐
    │ ❌ Senha verificada como inválida                   │
    │ ↓                                                   │
    │ ModelState.AddModelError("",                        │
    │   "CPF ou senha inválidos.")                        │
    │ ↓                                                   │
    │ return View(model);                                 │
    │ ↓                                                   │
    │ Views/Auth/Login.cshtml com erro exibido           │
    └─────────────────────────────────────────────────────┘

7. ACESSO À ÁREA PROTEGIDA
   ┌─────────────────────────────────────────────────────┐
   │ GET /Funcionario/Index (com cookie)                 │
   │ ↓                                                   │
   │ [Authorize] verifica autenticação                    │
   │ ├─ Cookie presente? SIM                             │
   │ ├─ Cookie válido? SIM                               │
   │ ├─ Expirou? NÃO                                     │
   │ └─ Claims válidas? SIM                              │
   │ ↓                                                   │
   │ FuncionarioController.Index() executado             │
   │ ↓                                                   │
   │ User.FindFirst(ClaimTypes.NameIdentifier)?.Value    │
   │ User.FindFirst(ClaimTypes.Name)?.Value              │
   │ User.FindFirst("cpf")?.Value                        │
   │ ↓                                                   │
   │ View exibida com sucesso                            │
   └─────────────────────────────────────────────────────┘

8. LOGOUT
   ┌─────────────────────────────────────────────────────┐
   │ POST /Auth/Logout (clica botão logout)              │
   │ ↓                                                   │
   │ AuthController.Logout()                             │
   │ ↓                                                   │
   │ await HttpContext.SignOutAsync(                      │
   │   "FuncionarioScheme")                              │
   │ ↓                                                   │
   │ Cookie "FuncionarioAuth" removido                   │
   │ ↓                                                   │
   │ RedirectToAction("Index", "Home")                   │
   │ ↓                                                   │
   │ 302 Redirect → /Home/Index                          │
   │ ↓                                                   │
   │ User não autenticado (cookie removido)              │
   └─────────────────────────────────────────────────────┘

FLUXO DE DADOS DURANTE O LOGIN:

CPF + Senha (texto puro)
         ↓
AuthController.Login()
         ↓
AuthSqlRepository.AuthenticateFuncionario()
         ↓
SQL Query (SELECT FROM pessoas WHERE cpf = @Cpf)
         ↓
Dados do banco (id, nome, cpf, HASH_armazenado, email)
         ↓
PasswordHasher.VerifyHashedPassword(hash_do_banco, senha_fornecida)
         ↓
    ┌────┴────┐
    ↓         ↓
  ✅ OK    ❌ FAIL
    ↓         ↓
 Cria     Retorna
 Claims   erro
    ↓
SignInAsync()
    ↓
Cookie "FuncionarioAuth"
    ↓
Navegador recebe cookie
    ↓
Próximos requests incluem cookie
    ↓
[Authorize] valida cookie
    ↓
Rota acessada com sucesso
