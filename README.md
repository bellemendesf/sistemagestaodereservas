# Sistema de Reservas de Restaurantes

Sistema web para gerenciamento de reservas em restaurantes, desenvolvido como projeto acadêmico na FATEC São José do Rio Preto.

A aplicação permite consultar restaurantes, visualizar os horários disponíveis e realizar reservas de acordo com a disponibilidade de mesas e ambientes.

## Tecnologias

* C#
* ASP.NET MVC
* HTML
* CSS
* JavaScript
* SQL Server
* Git e GitHub

## Objetivo

O projeto tem como objetivo facilitar o processo de reservas, organizando a disponibilidade dos restaurantes e proporcionando uma experiência simples para o usuário.
