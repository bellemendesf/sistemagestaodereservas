# 🍕 Sistema de Gestão de Reservas — Santa Massa

Sistema web desenvolvido para auxiliar no gerenciamento de reservas de mesas do restaurante **Santa Massa**.

## 📌 Sobre o projeto

O projeto está sendo desenvolvido como parte de uma atividade interdisciplinar do curso de **Análise e Desenvolvimento de Sistemas da FATEC São José do Rio Preto**.

A proposta é desenvolver uma aplicação web que facilite o gerenciamento das reservas e das operações relacionadas ao restaurante, proporcionando uma organização mais prática e eficiente.

Atualmente, o sistema está em desenvolvimento e conta com funcionalidades de cadastro, gerenciamento e integração com banco de dados.

## 🛠️ Tecnologias utilizadas

- **C#** — Linguagem de programação.
- **ASP.NET Core MVC** — Desenvolvimento da aplicação web.
- **SQL Server** — Gerenciamento do banco de dados.
- **ADO.NET** — Conexão e operações com o banco de dados.
- **HTML5 e CSS3** — Estrutura e estilização das páginas.
- **JavaScript** — Interatividade.
- **Bootstrap** — Componentes e responsividade.
- **Git e GitHub** — Versionamento e trabalho em equipe.

## ⚙️ Funcionalidades

- Autenticação de clientes e funcionários.
- Cadastro e gerenciamento de clientes.
- Cadastro e gerenciamento de funcionários.
- Gerenciamento de ambientes e mesas.
- Criação e gerenciamento de reservas.
- Integração com banco de dados SQL Server.

*As funcionalidades estão sendo implementadas e aprimoradas durante o desenvolvimento.*

## 🏗️ Estrutura do projeto

A aplicação utiliza o padrão arquitetural **MVC (Model-View-Controller)**, com organização em Models, Views, Controllers e Repositories.

O acesso aos dados é realizado por meio de **ADO.NET**, utilizando consultas SQL e repositórios.

## 👩‍💻 Desenvolvimento

Projeto desenvolvido em equipe, com foco na aplicação prática de conceitos de programação, engenharia de software, desenvolvimento web e banco de dados.
